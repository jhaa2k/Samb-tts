# IndicF5 reference audio

Place the speaker-approved reference recording at `engine/reference/ref.wav`.

- 5–10 seconds of clean, single-speaker Sambalpuri speech
- WAV, 24 kHz, mono (PCM 16-bit recommended)
- Set `INDICF5_REF_TEXT` to the exact transcript in Odia script
- Obtain explicit informed consent from the speaker

The actual recording is deliberately not committed here. Add it only with the speaker's permission.
